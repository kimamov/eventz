# eventz

A small platform for local events (parties and similar): accounts, event list and detail pages, joining events with guests, and filtering by location.

Built as a practice project for senior-level full stack work.

## Stack

- [Bun](https://bun.sh) as runtime, package manager and test runner
- [Hono](https://hono.dev) for the API
- [TanStack Start](https://tanstack.com/start) + React for the web app
- [AWS Emulator](https://docs.aws.amazon.com/emulator/latest/userguide/) for running AWS services locally
